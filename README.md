
# Raghu Works — Independent Digital Studio

**Design. Develop. Deliver.**

Raghu Works is an independent freelance digital services business focused on website design, web development, and creative digital solutions.

This repository contains the official Raghu Works website, which serves as a business portfolio, service catalogue, project showcase, and contact platform for potential clients.

## Overview

The purpose of this website is to:

- Introduce Raghu Works and its services.
- Showcase website development and digital design projects.
- Demonstrate technical and creative capabilities through project examples.
- Help potential clients understand available services.
- Allow visitors to submit project enquiries.

Raghu Works works with individuals, startups, and businesses that need websites and other digital solutions.

## Running Locally

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in a browser.

Alternatively, install the Live Server extension in VS Code and use it to run the website locally.
